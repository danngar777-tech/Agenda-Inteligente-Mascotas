# Manual de Usuario

## Introducción

El Sistema de Agenda Inteligente para Mascotas permite administrar el cuidado y seguimiento de las mascotas mediante el registro de información, programación de citas y control del historial médico.

---

# Inicio de Sesión

1. Ingresar a la plataforma.
2. Digitar usuario y contraseña.
3. Presionar el botón "Iniciar Sesión".

---

# Registro de Mascotas

1. Seleccionar la opción "Registrar Mascota".
2. Completar la información solicitada.
3. Presionar "Guardar".
4. Verificar la confirmación del registro.

---

# Gestión de Mascotas

1. Seleccionar una mascota registrada.
2. Editar la información necesaria.
3. Guardar los cambios.

---

# Programación de Citas

1. Acceder al módulo Agenda.
2. Seleccionar la mascota.
3. Elegir fecha y hora.
4. Seleccionar el tipo de cita.
5. Guardar el evento.

---

# Consulta de Historial Médico

1. Seleccionar una mascota.
2. Acceder a Historial Médico.
3. Revisar vacunas, tratamientos y observaciones.

---

# Recordatorios

El sistema notificará automáticamente:

- Vacunas próximas.
- Citas veterinarias.
- Tratamientos pendientes.
